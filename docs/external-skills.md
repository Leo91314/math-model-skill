# 外部技能与插件入口

下列能力在历史项目中使用或作为配套入口提及。完整运行依赖由对应产品提供，不把商业插件代码或其内部运行库复制到本仓库。

| 入口 | 本项目用途 | 恢复方式 | 收录状态 |
|---|---|---|---|
| documents:documents | Word读取、导出与渲染 | 在Codex启用对应Documents插件/工作区依赖 | 仅登记；本机许可明确限制提取和复制 |
| spreadsheets:Spreadsheets | Excel附件与指定结果模板 | 在Codex启用对应Spreadsheets插件及其运行库 | 仅登记，未复制插件文件 |
| pdf:pdf | 插件版PDF处理 | 启用对应PDF插件；普通本地PDF处理另有仓库内Apache版pdf技能 | 仅登记插件；不冒充两者完全等效 |
| deep-research-work:deep-research | 历史调研阶段 | 通过产品可用的Deep Research入口恢复 | 本机原插件快照已不存在，仅保留历史登记 |
| nature-data | 英文期刊数据声明 | 本机另有该技能，按任务需要使用 | 历史记录为已有能力，不据此声称赛题中实际调用 |
| systematic-debugging | 后续推荐的排错技能 | https://github.com/obra/superpowers/tree/main/skills/systematic-debugging | 仅推荐，未据本项目安装证据打包 |
| exploratory-data-analysis / citation-management / statistical-analysis | 后续推荐的数据审查、引文与统计技能 | https://github.com/K-Dense-AI/scientific-agent-skills | 仅推荐，未据本项目安装证据打包 |

插件版本和可用性以所用客户端为准。复制一个SKILL.md不能替代插件授权、连接器或运行时。
