# 技能目录

现行可安装技能共35个：原创七步7个、BZD 12个、科学计算6个、本机配套10个。旧版16入口单独归档，不进入默认安装。

“收录”不等于“每项均在赛题中实际调用或验证”；第三方保留原作者名称，配套技能为整理日现有版本。
