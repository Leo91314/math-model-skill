# 数据核查：让每个输入含义明确、来源可追溯

目标是判断真实输入能支持哪些问题，并消除会改变答案的数据错误。首次使用本系列且尚未读过时，阅读[共同原则](../liminghao-skill0-workflow/references/principles.md)；仍以本次用户范围和已有材料为准。

## 输入与边界

最少需要实际附件及字段说明；字段含义依赖题面时，读取相关原文。先复用会话和项目资料，不重复索要。只有数据而无题面时，可以检查文件结构和内部一致性，不能声称已验证题意适配。无真实数据时交付缺口与可执行读取方案，不用环境演示或合成数据代替赛题输入。

原件保留在 `data/raw/`，只向 `data/processed/` 写衍生数据；用户指定路径或测试隔离目录优先。计算使用项目 `.venv/bin/python`。表格、PDF等按需使用已安装的对应技能，不以安装或全面环境审计作为前置步骤。

## 会改变后续求解的检查

1. **先实际打开材料。** 列出与当前任务相关的文件、表单、尺寸、字段和单位，抽读首尾及有代表性的记录。阅读附件说明、合并单元格和多行表头，避免把说明行当观测。图片或扫描表无法可靠识别的关键数字应标记并核对，不能默默猜值。
2. **确定一行是什么。** 判断数据粒度、主键和各表连接关系：一行是一个时刻、节点、构件、工况，还是汇总量。检查编号唯一性、关联覆盖率和连接后的行数，防止多对多连接重复放大总量。编号可为文本，前导零不能随意丢失。
3. **统一物理和统计口径。** 核对角度/弧度、长度、时间、坐标原点与方向、时区、正负号和累计量/瞬时量。换算保留原字段含义与系数；区分观测值、题设常数、设计变量和推算量。对时间序列查乱序、重复时间和间隔，对几何数据查连接编号与空间范围。
4. **只处理有证据的问题。** 分清缺失、零值、检测下限和无效标记；异常值先定位原记录并判断机制。不能仅因偏离均值就删除，也不能默认插值或均值填补。修正需给依据，无法确定则保留并提出会影响结果的处理分支。有限工作时间优先处理阻断基线或显著影响核心指标的问题。
5. **避免从未来或答案借信息。** 若后续涉及预测、拟合或泛化评价，先确认按时间、对象或工况划分的边界，再拟合缩放、插补等处理参数；不得让测试信息进入训练。纯物理计算不强行设置训练测试集。
6. **导出并走一次真实接口。** 用实际小样本重新读取衍生文件，检查类型、行数、单位及约束范围能否进入求解程序。清洗代码保留输入输出和关键选择；发现“无须清洗”也可直接保留原数据并说明理由，不制造无用副本。

## 输出与完成条件

默认将必要报告写入 `outputs/workflow/03-data.md`，预处理代码放 `src/`；简短诊断可直接回复，不强制建报告。报告给出字段含义、来源、处理动作及行数变化、主要异常的具体位置，以及当前数据能够支持和暂不能支持的任务。不要展示一长串没有影响的常规统计。

完成意味着：关键输入实际可读、语义与关联清楚、每项会改值的处理有依据，且剩余缺口被传递给建模与基线阶段。大数据只抽样核查时明确覆盖范围，不宣称全量无误。

## 失败分流与阶段接口

- 读取失败：先区分格式、编码、损坏和工具缺失，尝试最短可行读取路径；不能把格式失败解释成数据为空。
- 语义矛盾：返回原题/附件说明定位冲突，仅询问无法从现有材料确定、又会改变结论的信息。
- 参数不足：区分可从现有数据推导、需文献补足及必须由用户提供；保留可独立开展的核查。

向 `liminghao-skill6-model` 和 `liminghao-skill7-baseline` 交付实际路径、单位、对象粒度、关联键与尚未解决的输入风险；不要自动扩展到所有模型的探索性分析。
